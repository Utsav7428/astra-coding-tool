# ASTRA Backend

A local-first AI IDE backend inspired by Cursor.

## Features

- Open local workspace
- Recursive workspace scanning
- File tree generation
- Read files
- Save files
- Create files & folders
- Rename files & folders
- Delete files & folders

## Tech Stack

- Java 21
- Spring Boot
- Maven
- Java NIO
- Lombok
